# CyberWM Pi Context Pack

Copy/unzip the contents of this pack into the root of `cyberwm_starter`.

It adds:

```text
AGENTS.md
MEMORY.md
TODO.md
PI_FIRST_SESSION.md
docs/
```

It does not overwrite the existing project code.

Recommended:

```bash
cd ~/Documents/153/cyberwm_starter
unzip /path/to/cyberwm_pi_context_pack.zip
```

Then read:

```text
PI_FIRST_SESSION.md
```

and launch:

```bash
pi
```

The most important file for Pi is `AGENTS.md`, because Pi core loads it automatically at startup.
