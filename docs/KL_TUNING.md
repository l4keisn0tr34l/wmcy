## Purpose

The zero-KL ablation improved several point metrics but collapsed stochastic rollout spread. This experiment asks whether a smaller nonzero KL weight can preserve posterior/prior regularization while retaining forecasting and security performance.

## Isolation and selection

The tuner loaded only train and validation data during screening and confirmation. It loaded test arrays only after fixing both KL setting and seed. This is asserted in the output as:

```text
screening_used_test: false
confirmation_used_test: false
```

Nine settings were screened with seed 7:

```text
KL weight: 0, 0.01, 0.03, 0.1, 0.3
free nats: 0 or 1 for nonzero KL
```

Candidates had to satisfy all validation gates relative to the published RSSM:

- state MAE no more than 3% worse;
- edge AP at least 90%;
- LM AP at least 90%;
- mean state spread at least 50%;
- mean host-permutation LM range no more than 1.5×.

Eligible candidates were ranked by a state-primary supported design score:

```text
state_MAE/reference
  - 0.25 * edge_AP/reference
  - 0.25 * LM_AP/reference
```

Lower is better. The top two settings were confirmed with seeds 7/17/27.

## Final test evaluation

The 20-rollout evaluation generated by the tuner is:

| Metric | Published RSSM | KL-tuned candidate |
|---|---:|---:|
| State MAE | 0.280 | **0.276** |
| Active-state MAE | 1.031 | **1.029** |
| Edge AP | 0.222 | **0.285** |
| LM F1 | 0.800 | 0.800 |
| LM AP | 0.910 | **0.926** |
| Pre-first-LM F1 | 0.769 | 0.769 |
| Pair top-1 | 0.143 (2/14) | **0.643 (9/14)** |
| Mean spread | 0.076 | 0.068 |
| Spread/error correlation | 0.613 | 0.679 |

The large pair result is promising but fragile: it is only 9 correct positive windows out of 14 on a repeatedly inspected controlled test split. It requires host-permutation/equivariance auditing and new episodes before it can be a headline.

ATT&CK test F1 for the tuned candidate is:

```text
T1046       0.700
T1110.001   0.746
T1021.004   0.875
```

## Episode behavior with 100 rollouts

A separate 100-rollout evaluation reduces Monte Carlo draw noise:

```text
test LM F1/AP:                   0.828 / 0.914
progressing episodes detected:  2/2
mean exact warning lead:        26.4 seconds
negative episodes alerting:     2/4
```

The same hard negatives still alert: scan-only and failed guessing. KL tuning does not solve the false-alert problem.

The difference between 20-rollout and 100-rollout AP/F1 estimates is itself evidence that finite Monte Carlo evaluation contributes noise. It does not change the selected checkpoint.

## Decision

Use KL 0.01/free 0 as the candidate initialization for the next decoder experiment because it passed all predeclared validation gates. Keep the original published RSSM as the stable report headline until:

1. pair behavior passes permutation/equivariance audit;
2. gains persist on new episodes;
3. stochastic spread is calibrated or at least stress-tested more broadly.

Do not describe this as deployment-calibrated uncertainty or independent generalization.
